# Contributing to Burnos

Start with the [setup guide](docs/GETTING_STARTED.md). Keep changes focused and describe the user-visible problem they solve.

For a bug report, include the Burnos commit/version, Windows version, Qt kit, configured model, steps to reproduce, and expected versus actual behavior. Remove keys, personal conversations, memory records, and account details from logs and screenshots.

For a pull request:

1. Explain the behavior before and after the change.
2. Build with the documented Windows kit.
3. Exercise the affected workflow with fictional data and report the result.
4. Update relevant setup, privacy, or feature documentation.

The repository has developer probe modes but does not currently contain a comprehensive automated application test suite. Do not label manual checks as automated coverage. Do not commit model weights, private configuration, runtime binaries, generated builds, or personal memory stores.

By contributing, you agree to license your original contribution under this repository's MIT License. Preserve existing third-party notices.
