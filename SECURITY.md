# Security

Use GitHub's **Report a vulnerability** option in this repository's Security tab to report suspected vulnerabilities privately. Do not post credentials, conversation histories, or memory-store contents in a public issue.

Include the affected commit, minimal reproduction using fictional data, impact, and any proposed mitigation. No response-time guarantee or formal support window is currently offered.

Burnos can invoke desktop, filesystem, command, browser, and connected-service tools with the current user's privileges. Use a standard Windows account and a disposable workspace when evaluating unfamiliar tasks. Model-generated instructions and external content are not trustworthy by default. Speaker matching is a convenience feature, not strong authentication.
