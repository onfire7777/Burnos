# Product feedback

Evidence-based draft prepared from the v0.22.0 source and development history. Technical assessments below are editorial recommendations, not invented first-person testimony. The entrant should supply their personal onboarding experience and confirm the reuse decisions before pasting this into Devpost.

| Tool / API / SDK | Used for | What worked well | What needs work | Onboarding evidence | Reuse recommendation |
| --- | --- | --- | --- | --- | --- |
| Qt 6 and Windows APIs | Native orb, audio, settings, process management, desktop automation | One native application coordinates speech and desktop work; DPAPI supports per-user key storage | Background input behavior differs across Win32 and WinUI; deployment needs matching plugins and compiler runtimes | Working app and dated input fixes are recorded; initial setup duration is not recorded | Yes, for native Windows control; retain framework-specific regression checks |
| OpenRouter | Conversation/task models and optional memory embeddings | Separate models can serve conversation and background work through one integration | Model modality and tool support must match the requested workflow; image incompatibility produced a documented 404 | A shortlist mismatch and recovery are documented in friction entry 1; personal first-use experience is not recorded | Yes, with capability validation and clear errors |
| whisper.cpp / Parakeet | Local speech recognition | Local decoding is integrated; the app supports a loaded-library path and CLI fallback | Runtime naming is easy to confuse with unrelated Parakeet projects; library ABI and model format need explicit versioning | Source shows the required CLI and DLL interfaces; no measured onboarding time is available | Yes, with pinned runtime instructions and audio tests |
| Silero VAD | Speech activity detection | Integrated local gating of speech before recognition | Sensitivity and pause settings depend on environment and microphone | Local implementation and user settings are visible in source | Yes, with representative microphone/noise checks |
| sherpa-onnx, Kokoro, keyword and speaker models | Local speech synthesis, wake detection, speaker matching | Reused runtime supports several voice features; model-loading code keeps engines available | With-TTS and no-TTS builds differ; exact C API version matters; wake/speaker behavior needs testing across voices | Dated wake-word and voice changes exist; personal setup feedback is not recorded | Yes, with pinned binaries and clear optional-model status |
| Mnemosyne and MCP | Persistent memory, retrieval, external tools | Memory is directly integrated, with SQLite persistence demonstrated independently | A historical capture returned an ID without retaining the expected record; callers need explicit write outcomes | Friction entry 4 and the isolated test supply concrete evidence; they do not prove every current path | Yes, with persistence checks and explicit protocol compatibility tests |
| Chromium DevTools protocol and PDF.js | Separate research browser, page and PDF reading | Research can operate in its own profile; PDF.js is embedded in the executable | Authentication, bot challenges, dynamic pages, and image-only PDFs limit extraction | The browser feature is documented in the October 13 commit | Yes, while exposing extraction limits and source links |
| Composio | Optional connected-service tools | Integration provides a route to user-authorized services | Setup, account permissions, and action outcomes require service-specific validation | Integration source exists; this preparation did not connect or exercise a real account | Conditional: confirm after an authorized end-to-end account test |
| Remotion and React | Animated product reveal and repository visuals | Reusable scenes, captions, and one consistent visual system | Animation must be clearly distinguished from live product evidence; renderer dependencies have separate licenses | The film was rendered and the editable source is included | Yes, for presentation and editing around real demonstrations |
